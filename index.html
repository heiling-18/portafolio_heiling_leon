Soy Heiling Gisselle León Bernal, desarrolladora de software en formación en Campuslands, con base técnica en Sistemas Teleinformáticos (SENA) y Producción Agropecuaria (UIS). Esta combinación me permite entender problemas operativos reales del sector productivo y comercial y convertirlos en soluciones tecnológicas prácticas.

Me destaco por construir aplicaciones completas desde cero: desde interfaces web interactivas con Next.js, TypeScript, HTML, CSS y JavaScript hasta sistemas backend estructurados con Java (POO, MVC, DAO), Python (FastAPI) y bases de datos MySQL / Supabase / MongoDB.

Además, integro sistemas de visión por computadora e IA (YOLOv8, GPT-4o, FiftyOne) y automatización de flujos con n8n bajo metodologías ágiles como SCRUM y control de versiones colaborativo con GitFlow.
